# کیبورد کانکی ⌨️

کیبورد اندروید سبک (فایل نصبی حدود ۴٫۵ مگابایت)، سریع و بی‌اینترنت؛ برای فارسی، انگلیسی، ترمینال و بازی.

## تازه‌های نسخه ۱٫۰٫۰
- کیبورد با Canvas خالص: لمس چندانگشتی، تایپ تند، پنجره‌ی حرکت‌ها با نگه داشتن، حباب کلید.
- فارسی استاندارد با کلید نیم‌فاصله، همه‌ی حرکت‌ها (فتحه، کسره، ضمه، تنوین، سکون، تشدید)، رقم فارسی یا لاتین؛ انگلیسی و عربی.
- **کشیده‌نویس هوشمند** (کم، متوسط، زیاد): «ـ» فقط بین حروف چسبان؛ «لا» و حروف بی‌اتصال سالم می‌مانند.
- **حالت خام برای ترمینال و بازی** (Termux، SSH، پابجی): هر حرف مستقیم، کلیدها با KeyEvent واقعی؛ نوار ترمینال با ESC، TAB، CTRL و ALT چسبنده، جهت‌ها و | / \ ~ $ { } [ ].
- **استودیوی فونت**: ۵۰+ فونت یونیکد (گوتیک، دوخطی، دایره‌ای، زالگو، ...)، تایپ زنده با فونت، قالب‌های فارسی، تگ کلن و قاب نام گیمری (꧁༒ نام ༒꧂).
- **تایپ صوتی آفلاین** (Vosk): مدل فارسی یا انگلیسی فقط با درخواست خودت دانلود می‌شود؛ کلمه‌ها همان لحظه می‌آیند؛ «نقطه»، «ویرگول»، «علامت سوال»، «خط بعدی».
- **کلیپ‌بورد هوشمند**: تاریخچه، سنجاق، پاک شدن خودکار رمز و کد یک‌بارمصرف و کارت.
- ایموجی، کائوموجی و هنر متنی؛ میان‌بر متنی (`@@` ← ایمیل)؛ حرکت نشانگر با کشیدن روی فاصله؛ پاک کردن کلمه‌به‌کلمه با کشیدن پاک‌کن.
- تم شیشه‌ای تیره: سایبرپانک نئون، AMOLED مشکی، ابسیدین، آبی یخی، رنگ دلخواه؛ ارتفاع ۷۰ تا ۱۳۰٪، یک‌دستی، لرزش و صدای کلید مکانیکی (بی فایل صوتی).
- بکاپ و بازگردانی همه‌چیز با یک فایل JSON.

## نصب
1. فایل APK مناسب گوشی را از Actions (artifact) بگیر: اکثر گوشی‌ها `arm64-v8a`.
2. برنامه را باز کن و دو قدم «راه‌اندازی» را بزن.

## حریم خصوصی
هیچ چیزی که تایپ می‌کنی از گوشی بیرون نمی‌رود. اینترنت فقط برای دانلود مدل صدا از سایت رسمی Vosk (با بررسی اثر انگشت فایل).
